# ПроПластФорм

Корпоративный сайт предприятия по литью пластмасс под давлением. По словам автора,
проект был завершён и передан заказчику. Публичная версия сейчас недоступна после
окончания оплаты хостинга Timeweb.

## Возможности

- презентация предприятия и производственных возможностей;
- разделы продукции, услуг и преимуществ;
- интерактивный расчёт;
- контактные и конверсионные блоки;
- адаптивная версия;
- базовая поисковая разметка, `robots.txt` и `sitemap.xml`.

## Технологии

- HTML;
- CSS;
- JavaScript;
- Tailwind CSS через CDN.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер.

В репозиторий намеренно не включены данные окружения, материалы развёртывания и
временные рабочие файлы.
